# AR Science Lab • แยกสาร ป.6

เกมการเรียนรู้ AR ผ่านเว็บ สำหรับฝึกเรื่องการแยกสาร ระดับชั้น ป.6

## สิ่งที่มีให้
- 20 ด่าน × 10 ข้อ = 200 ข้อ
- ตัวเลือก 4–5 ตัวเลือก ลอยและเคลื่อนที่ตลอดเวลา พร้อมระบบกันซ้อน
- ใช้ MediaPipe Hands ตรวจจับมือ โดยแสดงเฉพาะจุดสีบริเวณกลางมือ
- วางจุดสีบนคำตอบแล้วกำมือค้างเพื่อยืนยัน
- สรุปคะแนน ข้อถูก/ผิด และเฉลยหลังจบด่าน
- หน้าเลือกด่าน 20 ด่าน
- เมนูผู้ดูแลพร้อมรหัสยืนยัน
- ผู้ดูแลแก้ชื่อเว็บไซต์, แก้/เพิ่ม/ลบด่าน, แก้/เพิ่ม/ลบข้อสอบ, เปลี่ยนรหัสผู้ดูแลได้
- ข้อมูลเกมอยู่ที่ `data/game.json`

## รันบน VPS
ต้องติดตั้ง Node.js 18+ ก่อน จากนั้น:

```bash
npm install
npm start
```

เว็บจะฟังที่ `0.0.0.0:8080` โดยค่าเริ่มต้น ตั้ง `PORT` ได้ เช่น `PORT=9090 npm start`

## พฤติกรรมการเลือกคำตอบ
- กำมือเลือกข้อถูก: ตัวเลือกที่เลือกจะแสดงพื้นหลังสีเขียวแบบโปร่งใสและตัวอักษรยังอ่านได้ชัด
- กำมือเลือกข้อผิด: ตัวเลือกที่เลือกจะแสดงสีแดงแบบโปร่งใส พร้อมไฮไลต์คำตอบที่ถูกเป็นสีเขียว
- สีเฉลยจะแสดงค้างชั่วครู่ก่อนเปลี่ยนไปข้อถัดไป และจะไม่ทำให้การเลือกซ้ำในช่วงนั้น

## AR / กล้อง
บราวเซอร์ส่วนใหญ่ต้องการ **HTTPS** สำหรับ `getUserMedia()` เมื่อเปิดจากโดเมนหรือ IP จริง แนะนำให้วาง Nginx/Reverse Proxy หน้า Node แล้วออกใบรับรอง SSL

ตัวอย่างการรันหลังบ้าน:

```bash
PORT=8080 NODE_ENV=production npm start
```

จากนั้นให้ Nginx รับ HTTPS และ proxy ไป `http://127.0.0.1:8080`
